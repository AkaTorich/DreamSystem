# Recognizing and reading REAL Egyptian before declaring gibberish

Short strings defeat statistics. Before running the pseudo-translation game, check the
input against these common real-world strings (tattoos, souvenirs, textbooks quote them
constantly).

## Royal names in cartouches (phonetic alphabet reading)

If 𓍹 … 𓍺 encloses signs, read them phonetically with the uniliteral alphabet:

𓄿 ꜣ (a) · 𓇋 j/i · 𓏭 y · 𓂝 ꜥ (a) · 𓅱/𓏲 w/u · 𓃀 b · 𓊪 p · 𓆑 f · 𓅓 m · 𓈖 n · 𓂋 r/l ·
𓉔 h · 𓎛 ḥ · 𓐍 ḫ · 𓄡 ẖ · 𓋴/𓊃 s · 𓈙 š (sh) · 𓈎 q · 𓎡 k · 𓎼 g · 𓏏 t · 𓍿 ṯ (tj) ·
𓂧 d · 𓆓 ḏ (dj) · 𓃭 rw/l · 𓍯 wꜣ · 𓆇 (egg: female name determinative)

Worked example — 𓍹𓈎𓃭𓇋𓍯𓊪𓄿𓂧𓂋𓄿𓏏𓆇𓍺:
q + l + i + w(a) + p + a + d + r + a + t + (fem.) = **Qlwpadrat = Cleopatra** (Κλεοπάτρα).

Other frequent souvenir cartouches: Tutankhamun (𓇋𓏠𓈖𓏏𓅱𓏏𓋹 — "Amun" written first
honorifically), Ramses (𓇳𓄟𓋴𓋴 ra-ms-s-s), Nefertiti, and modern tourist names spelled
with the alphabet above — if the phonemes spell a modern name, say so!

## How to answer for real text

Transliterate what you can, translate what you recognize, and be explicit about
uncertainty ("знак 𓐎 здесь может быть детерминативом…"). No pseudo-translation fantasy
for real text — the honest reading IS the deliverable. Offer the fantasy game only as
an explicit extra if the user wants it for the unreadable leftovers.
