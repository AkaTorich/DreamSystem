# Карта снов · сайт (PHP/MySQL)

Сервер «Карты снов»: аккаунты, сны, библиотеки, дары, космос. Сайт показывает ту же программу, что
на устройствах, — сайтовую версию CrossDream: она лежит прямо в корне (`index.html`, `css`, `fonts`, `js`, `shim`, `vendor`),
собирается и заливается `CrossDream\tools\build-web.ps1 -Deploy` (серверная часть — `CrossDream\tools\deploy-web.sh`).
Прежние страницы (карта, библиотека, космос, вход,
импорт) убраны 14.11.2026 — они в истории git.

## Требования
- PHP 7.4+ (расширения: pdo_mysql, curl; желательно gd для сжатия картинок)
- MySQL / MariaDB

## Установка
1. Создать базу: выполнить `schema.sql` (в phpMyAdmin или `mysql -u root -p < schema.sql`).
2. Прописать доступ к БД в `config.php`.
3. Положить папку на сервер (для XAMPP — в `htdocs/dreamweb`), убедиться что `uploads/` доступна на запись.
4. Открыть сайт и зарегистрироваться во вкладке «Сайт». **Первый зарегистрированный аккаунт становится админом.**

## Импорт из настольной программы
Кнопка «⋯» → «Импорт снов» в программе (на Windows — перенос из прежней программы, везде — файл
`dreams.json`). Повторный импорт не создаёт дублей (сны узнаются по id программы).

## ИИ
Ключ OpenRouter вводится каждым пользователем в «Настройках» своего аккаунта (хранится в БД).
Анализ сна, поиск связей и генерация картинки локации идут через сервер (PHP curl).
Модели выбираются в настройках, подсказки цен подтягиваются с OpenRouter.

## Роли
- **Сновидец**: своя карта, запись/импорт снов, свои связи.
- **Админ**: страница «Космос» — карты всех сновидцев на одной; правка и удаление
  любых снов и связей; мосты между снами разных сновидцев (пунктирные линии).

## Файлы
- `api.php` — весь JSON-API (auth, сны, связи, импорт, космос)
  - `img` — картинки снов только через проверку доступа; `&s=1` — маленькая копия для карты
  - `add_links` — нити пачкой (синхронизация из программы), те же права, что у `add_link`
- `lib/` — БД, сессии, OpenRouter
  - `lib/ai.php` · `make_thumb()` — миниатюра для кружка на карте: квадрат 160×160 из середины, WebP ~3–5 КБ,
    `uploads/thumbs/<имя>.webp`; делается при сохранении картинки или при первом запросе `img&s=1`;
    удаляется вместе с большой. Программа скачивает миниатюры при синхронизации
  - `api.php` · обложки PDF — `uploads/pdfcovers/<файл>.webp` (160 точек, ~2 КБ, Ghostscript + ImageMagick):
    печёт `pdf_cover_bake()` при `pdf_add`, все прежние — `tools/bake-covers.sh`; `pdf_cover` отдаёт,
    `pdf_cover_set` принимает JPEG и переводит в WebP; `pdfs_list` отдаёт `size` и `has_cover`
  - папки полок — вложенность любая (`folders.parent_id`): `folder_create {parent}`, `folder_move`,
    `folder_del` поднимает вещи и подпапки на уровень выше
  - `lib/libops.php` — личная библиотека: `items_copy`, `folder_copy`, `pdf_rename`, `file_rename`.
    Удаление (`pdf_del`, `file_del`, дыра) убирает только запись — файлы на сервере копятся всегда;
    стереть файл совсем у всех — `lib_purge`, только владелец сайта
  - `lib/image.php` — картина сна рисуется сразу маленькой: через OpenRouter Images API с самыми быстрыми
    настройками, которые понимает модель (низкое качество, наименьшее разрешение, 4:3 или ближайшая
    пропорция; список умений моделей — `uploads/image_models.json`, обновляется раз в сутки), затем
    обрезается и ужимается ровно до 640×480 (`save_image_640x480`). Модели нет в Images API — рисуется
    по-старому через чат. Загрузки картин из программы (`set_image`) не обрезаются
  - `lib/ai.php` · `or_chat()` — перегрузка у поставщика модели (429, 502, 503) повторяется дважды (через 3 и 7 с);
    любая непойманная ошибка в `api.php` отдаётся понятным ответом `{error}` (502), а не пустым «HTTP 500»
  - `lib/reset.php` — восстановление доступа по почте: `reset_request {who}` (логин или почта; ответ всегда
    одинаковый; письмо с info@globthe.top не чаще раза в 3 минуты на аккаунт и 5 в час с адреса),
    `reset_confirm {token, pass}` (ссылка одноразовая, живёт час, в базе — только хеш), `set_email {email}`;
    таблица `pass_resets`, поле `users.email`. Страница ссылки — `reset.php` («Забыли пароль?» во вкладке «Сайт»)
- `reset.php` — страница нового пароля по ссылке из письма; ей нужны `assets/style.css` и `assets/common.js`
- `index.html` и папки рядом — сайтовая версия программы (не править здесь: она собирается из `CrossDream\app\ui`)
- `.htaccess` на сервере (не этот, локальный для XAMPP): старые адреса `login.php`, `logout.php`, `biblio.php`,
  `admin.php`, `import.php`, `index.php` и `/app/` переводятся на главную (301); скрипты и стили — `no-cache` — чтобы закладки и старые ссылки не падали в 404
