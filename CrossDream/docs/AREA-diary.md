# Область «Карта и дневник» — что где

Четыре папки одной области: `map`, `dreams`, `account`, `admin` (каждая — `index.js` с `init(ctx)`).
Между собой эти папки импортируют друг друга напрямую (один хозяин); с чужими областями — только шина.

## js/map — карта
| файл | что в нём |
|---|---|
| `index.js` | вход области: небо, сфера, легенда, чёрная дыра; слушает `map:focus`, `user:changed` |
| `view.js` | одна карта — два режима: своя (`rebuildOwn`) и чужая (`showForeign` для космоса); пустая заставка `#empty`; `focusDream` |
| `own.js` | своя карта: сны → узлы, планеты (от 2 снов или с книгой-фундаментом), нити; перетаскивание → `positions_save` / `planet_set`, двойной клик по планете — ровная орбита, вид → Settings + `save_view` |
| `legend.js` | `#legend`: глаз «👁 нити» (Settings.MapLinks) и цвета типов |
| `palette.js` | личная палитра (нити, сон, планета): из `user.colors`, без входа — память устройства |
| `sky.js` | небо как в программе: градиент, три туманности, звёзды без мерцания; перерисовка только после смены размера |
| `engine/sphere.js` | движок сферы: данные, проекция, зум к точке, `focusNode`; рисует только по `redraw()` |
| `engine/physics.js` | шаг раскладки (отталкивание, нити, стенка сферы) |
| `engine/draw.js` | отрисовка узлов, нитей, колец, подписей |
| `engine/input.js` | мышь и пальцы: сдвиг, щипок, колесо, тап/двойной тап, перетаскивание узла |

## js/dreams — дневник
| файл | что в нём |
|---|---|
| `index.js` | вход: `btnNew`, `btnList`, `menuImport`, `dream:open`, Esc (окно → карточка → чужие панели → левая) |
| `store.js` | общая память: сны, планеты, книги-фундаменты, вошедший, Settings; `reload` по `dreams:reload` и `dreams://changed`; картинки снов через `dream_image` |
| `form.js` | запись нового сна → `dream_save` → разбор (`pipeline.js`); без входа — только локация руками |
| `pipeline.js` | окно хода разбора: события `pipeline://step`, `dream_analyze` |
| `list.js` | список снов с поиском |
| `card.js` | карточка сна: картина, толкование, образы, нити, запись, гадания (`oracle:open`), книга (`library:open`) |
| `card-edit.js` | правка записи и локации, удаление, снятие нити, ↻ достройка, `linkByLocation` |
| `picture.js` | картина: из прежнего сна, из файла (`dream_set_image`) или нарисовать заново |
| `import.js` | `legacy_import` и чтение dreams.json (диалог Tauri, запасной путь — выбор файла окном) |
| `modal.js` | окна: `showModal`, `ask`, `askText`, `choose`, Esc-стек (`closeTop`, `addEscape`) |
| `panels.js` | боковые панели `drawer` в `#panels` |
| `util.js` | экранирование, иероглифы в тексте, `shortLoc`, даты, base64, `addCss`, `narrow` |

## js/account — аккаунт
| файл | что в нём |
|---|---|
| `index.js` | вход: `btnSite`, `menuSettings`; после `app:ready` — `site_state` |
| `site.js` | окно «⛅ Сайт»: вход/регистрация по инвайту, сервер, выход, `sync_all`; `applyUser` → `ui.showUser` + `user:changed` |
| `settings.js` | «⚙ Настройки»: палитра, GenImages, PdfZoom, пароль и ключ ИИ (после входа), модели — владельцу |
| `models.js` | подсказки моделей OpenRouter |

## js/admin — управление (через `api.site`)
| файл | что в нём |
|---|---|
| `index.js` | вход: `menuUsers`, `btnGifts` (бейдж), `btnTrust`, `menuCosmos` |
| `users.js` | пользователи: ник, роль, доступ к ИИ, пароль, бан, удаление |
| `invites.js` | инвайты: создать, скопировать, удалить, подчистить (владелец) |
| `gifts.js` | ларец даров, чёрная дыра глотает дар (`#blackHole.feeding`) |
| `trust.js` | связи доверия, автоприём |
| `cosmos.js` | космос сновидцев и карта сновидца (`#cosmosBar`, `#dreamers`) |
| `cosmos-card.js` | карточка чужого сна: правка, удаление, нити, мост 🔗 (`#linkbar`) |

## css
`map.css`, `dreams.css`, `account.css`, `admin.css` — подключаются из своих `index.js`; у каждого свой
блок `@media (max-width: 760px)`. `mobile.css` — общие правила узкого экрана (шапка, панели во всю
ширину, окна, крупные кнопки и поля 16px).

## Свои события шины (только между моими папками)
- `dreams:close-left` — закрыть левую панель (после записи сна).
