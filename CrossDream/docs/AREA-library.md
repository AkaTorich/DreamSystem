# Библиотека, читалка PDF, гадания, сборка — что где

## Библиотека (`app/ui/js/library/`, стили `app/ui/css/library.css`)
| Файл | Что в нём |
|---|---|
| `index.js` | вход: кнопка `btnLibrary`, шина `library:open {tab?, bookNum?, pdfId?}`, `user:changed`, `ui:escape`, событие ядра `library://changed` |
| `state.js` | общее состояние: вкладка, книги, PDF, сюита, раскладка по папкам, отбор, режим связывания |
| `data.js` | ядро и сайт: `books_get/books_save`, `pdfs_list`, раскладка (`lib_index` ядра сразу, `site('lib_index')` — тихая сверка), id вещей на сайте, отправка всей библиотеки (`books_import`) |
| `shell.js` | страница полок: вкладки Иероглифы / PDF / Сюита, счёт, панель действий («Новая папка», «Вставить», «Выбрать», «Добавить»), путь папки «Все полки / А / Б», полоса отбора |
| `tabs.js` | смена вкладки, «➕» (книга или PDF), выбор другого books.json (Settings.BooksPath) |
| `shelves.js` | карточки папок, книг, PDF (с обложками), инструментов сюиты |
| `folders.js` | папки с вложенностью любой глубины (`parent_id` на сайте): открыть, на уровень выше, новая папка в открытой, переименовать, убрать (содержимое — на уровень выше); отбор нескольких |
| `clip.js` | буфер и действия: копировать / вырезать → вставить (`items_copy`, `items_move`, `folder_copy`, `folder_move`), переименовать, удалить из библиотеки (файлы на сервере остаются), стереть с сервера (`lib_purge`, только владелец сайта) |
| `ctxmenu.js` | выпадающее меню действий по правой кнопке или долгому нажатию: по вещи, по папке, по пустому месту |
| `reader.js` | читальня книги иероглифов: текст, ключ трактовки, кнопки 🪐 🔗 ✏ 🎁 🗑 |
| `bookactions.js` | трактовка ИИ через сайт (`book_interpret` с ключом), фундамент, дар, удаление |
| `bookform.js` | новая книга и правка; печать скилла уезжает на сайт, местный текст чистится |
| `links.js` | связи книг: режим связывания, список связей, переход к связанной книге, обмен трактовкой с сайтом |
| `pdflink.js` | стык с читалкой PDF: открыть том с полки, крючки (связать, связи, удалён, закрыта) |
| `covers.js` | обложки PDF: готовые WebP с сайта (ядро `cover_get`), для книг только на устройстве — первая страница pdf.js → `cover_put`; только видимые карточки |
| `suite.js` | полка сюиты: значки (`site_download`), скачивание (`suite_download`) |
| `seals.js` | шрифт Писца (PUA) → юникод, печати скилла скрыты, куски иероглифов |
| `keys.js` | ключи трактовки из книги «Ключи к трактовке» |
| `dialogs.js` | малые окна вместо prompt/confirm: строка, «да/нет», дар |
| `util.js` | экранирование, склонение, окна поверх (верхнее — последнее в `#overlays`), Esc только верхнему, base64 |

Шрифт иероглифов: `app/ui/fonts/NotoSansEgyptianHieroglyphs-Regular.ttf` (лицензия `fonts/OFL.txt`), `@font-face` — в `library.css`.

## Читалка PDF (`app/ui/js/pdf/`, стили `app/ui/css/pdf.css`)
| Файл | Что в нём |
|---|---|
| `index.js` | стили и Esc для читалки |
| `reader.js` | окно: масштаб (Settings.PdfZoom, Ctrl+колёсико), память страницы (`pdf_page_set`), защита от копирования, удаление |
| `pages.js` | страницы по мере прокрутки: места нужного размера, рисуются ближние, дальние освобождаются |
| `loader.js` | подключение `vendor/pdfjs` (pdf.js 3.11) по первому требованию |
| `add.js` | добавить PDF: ПК — диалог + `pdf_add`, телефон — выбор файла + `pdf_add_bytes` |

## Сборка (`tools/`)
| Файл | Что делает |
|---|---|
| `build-windows.ps1` | значок (`fix-ico.ps1`) → `cargo tauri build --bundles nsis -- --jobs 2` → `CrossDream.exe` и установщик в корень |
| `fix-ico.ps1` | мелкие размеры `icon.ico` несжатыми (иначе пустой ярлык) |
| `android-env.ps1` | JDK/SDK/NDK с диска `<буква>:\JavaSDK`, только для процесса |
| `android-init.ps1` | `cargo tauri android init --ci`, имя «Карта снов», интернет, подпись своим ключом `android-keystore\` |
| `build-android.ps1` | .so через Tauri → jniLibs копией → Gradle через свободную букву (subst) → `CrossDream.apk` |
| `build-linux.sh` | в WSL (Ubuntu): пакеты WebKitGTK, Rust, tauri-cli при первом запуске → копия исходников в `~/crossdream-build` → AppImage и deb в `builds/linux` |
| `run-debug.ps1` + `cdp.ps1` | запуск с портом WebView2 9222; код в окне, снимки (`-Shots папка` — 360, 768, 1280) |
| `..\.github\workflows\crossdream.yml` (в DreamSystem) | macOS dmg (universal), iOS (Linux — дома, `tools/build-linux.sh`) |
