# DreamSystem

«Карта снов» и всё, что вокруг неё: программа, сайт, моды Skyrim и защита.

## Что где

- **DreamMap** — настольная «Карта снов» (WPF, .NET 4.8): дневник снов, где сны — звёзды, места — планеты, а родство снов — нити. Установщик лежит в `installer`, руководство — в `docs`.
- **dreamweb** — веб-движок «Карты снов» (PHP/MySQL): аккаунты сновидцев, общий космос и обмен книгами.
- **HieroMod** — мод «Египетские иероглифы» для Skyrim SE: свой SWF-шрифт, генератор esp и программа «Писец».
  - В `mods_pack` из модов в репозитории только свои: «Египетские иероглифы», «Мир без вражды» и «Призрачный страж».
- **Skymir** — достаёт книги Skyrim из плагинов и сейвов, считает по ним статистику и верстает PDF.

В репозиторий не попадают:
- сборки (bin, obj, build, dist, exe, dll);
- чужие моды и файлы игры;
- Themida;
- пароли, ключи и сертификаты.
