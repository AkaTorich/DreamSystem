# Карта снов · программа (WPF, .NET Framework 4.8)

Дневник снов с картой: сны — звёзды, места — планеты, родство снов — нити.
Работает и без интернета; вход на сайт `dream.globthe.top` добавляет ИИ, синхронизацию,
космос сновидцев и обмен книгами.

Сборка: `dotnet build -c Release` → `bin\Release\net48\DreamMap.exe`.
Установщик: `installer\Установка Карты снов.spec` (pyinstaller) → `installer\dist\`.
Ставит программу в `%LOCALAPPDATA%\DreamMap`, ярлык на стол и папку «Карта снов» в Пуск.
Данные пользователя — отдельно, в `%APPDATA%\DreamMap` (по папке на аккаунт).

Верхняя панель: кнопки окна и главные действия стоят справа первыми и видны при любой ширине;
космос, пользователи, импорт и настройки — в меню ☰. Внизу — строка состояния с ходом синхронизации.

## Что где

| Файл | Что внутри |
|---|---|
| `MainWindow.xaml.cs` | поля окна, запуск, настройки и мелочи (тосты). «Весь экран» — рабочая область монитора, панель задач остаётся видна (`SetFull`, `WorkAreaHere`). Меню ☰ (`More_Click`) |
| `MainWindow.Status.cs` | строка состояния внизу: что делает синхронизация и полоса её хода (`SyncBegin` / `SyncPart` / `SyncStep` / `SyncEnd`) |
| `MainWindow.Audit.cs` | проверка вёрстки: `DreamMap.exe --layout-check <отчёт.txt>` открывает все окна и панели при 1024×700, 1366×768 и во весь экран и пишет, что обрезано или вылезло за край; потом закрывается |
| `MainWindow.Sky.cs` | небо и легенда. Небо печатается **одной картинкой** (`BuildSky`), при растягивании окна пересобирается, когда окно замрёт (`QueueSky`); звёзды не мерцают. Глаз «нити» (`LinksToggle`) |
| `MainWindow.Graph.cs` | карта: узлы, планеты, нити, проекция, физика (`SimStep` — дальние пары не считаются), перетаскивание. Свечение узла — нарисованный ореол (`MakeHalo`), не эффект |
| `MainWindow.Pipeline.cs` | конвейер записи сна, ИИ через сайт, выбор картинки |
| `MainWindow.Actions.cs` | действия со снами (удаление с «надгробием»), панели, карточка сна |
| `MainWindow.Site.cs` | вход на сайт и синхронизация. Список снов скачивается **один раз** за проход и отдаётся сверке позиций; нити уходят **пачкой** (`add_links`); картины — в обе стороны (`set_image`) |
| `MainWindow.Admin.cs` | пользователи, инвайты, дары, доверие, космос. Чёрная дыра в углу крутится только когда в неё скормлен дар (`SpinBlackHole`) — вечное вращение держало окно в постоянной перерисовке |
| `MainWindow.Library.cs` | библиотека книг СкайМира, сюита |
| `MainWindow.Folders.cs` | полки-папки (живут на сайте). Последняя раскладка хранится в профиле (`lib_index.json`): библиотека сразу открывается с папками, сайт сверяется тихо и перерисовывает полку, только если что-то поменялось (`LoadFoldersCached`, `LoadFoldersQuiet`) |
| `MainWindow.Pdf.cs` | PDF: обложки, читалка, кеш страниц, кнопки читалки |
| `MainWindow.BookLinks.cs` | связи книг |
| `Models.cs` | сны, настройки, хранилище (`Store`), надгробия удалённых снов |
| `SiteClient.cs` | запросы к сайту |
| `Vault.cs` | шифрование PDF и кеша (DPAPI + AES) |
| `AskWindow.cs` | окно ввода в стиле программы |
| `Stalkers\` | окна гаданий (Медичи, Оби и др.) |
| `docs\` | руководство (`Руководство.html`) и `Собрать PDF.ps1` |
